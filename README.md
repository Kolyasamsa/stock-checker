# Проверка остатков

Статическое браузерное приложение для проверки остатков.

## Как работает

1. Вставить таблицу `Остатки на сегодня`.
2. Вставить таблицу `Заказано`.
3. При необходимости вставить `Реализация с предыдущих дней`.
4. Нажать `Проверить остатки`.

Все расчёты выполняются в браузере. Сервер и база данных не нужны.

Нормализация номенклатуры встроена в `index.html` и основана на листе `форматирование названий`, колонках F:G файла `проверка.xlsx`.

## GitHub Pages

После загрузки `index.html` в репозиторий включите:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
